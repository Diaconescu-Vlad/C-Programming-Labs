# C Programming Fundamentals

A comprehensive collection of lab exercises and algorithmic challenges implemented in C, showcasing foundational programming skills.

## Overview

This repository serves as a portfolio of my practical coursework from the first semester at the National University of Science and Technology Politehnica Bucharest (UNSTPB). It contains a series of incremental lab assignments designed to build a strong grasp of procedural programming, logic building, and low-level memory management.

## Key Topics Covered

- Pointers and dynamic memory allocation
- String manipulation and character arrays
- Matrix operations and multi-dimensional arrays
- Custom data types using `struct`
- File I/O operations (reading and writing data)
- Implementation of standard algorithms (sorting, searching, data filtering)

## Prerequisites

To compile and run the source code, you will need:
- A standard C compiler (e.g., **GCC** via MSYS2 on Windows, or default GCC on Linux)
- A terminal or command line interface

## Compilation and Execution

The repository is organized by laboratory sessions (e.g., `Lab 2`, `Lab 3`). Since these are standalone exercises, you can compile any individual `.c` file using a standard `gcc` command. 

Navigate to a specific lab directory and compile a file (for example, `ex02.c`):

```bash
# Compile the source file
gcc -Wall -o ex02 ex02.c

# Run the compiled executable (Linux/macOS)
./ex02

# Run the compiled executable (Windows)
.\ex02.exe
```
